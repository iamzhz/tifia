# 小纸条

本目录下的 `.md` 文件会被 `g.py` 汇总成站点里的「小纸条」栏目（`/pieces/`），不会作为普通文章处理。

## 文件命名

文件名必须是下面三种日期格式之一：

- `2026.md` —— 按年
- `2026.08.md` —— 按月
- `2026.08.29.md` —— 按日

文件名只用于分档和排序参考，真正的排序依据是每条小纸条自己的日期。

## 文件内容

文件内每条小纸条用一个 Markdown 小标题开头，标题就是日期，时间可选：

```markdown
## 2026-08-29 (21:30)

今天把博客的小纸条栏目写好了，动态分页比想象中麻烦一点。

## 2026-08-28

没有时间也可以，按当天零点排序。
```

支持的标题日期写法：

- `2026-08-29`
- `2026-08-29 21:30`
- `2026-08-29 (21:30)`
- `2026-08-29（21:30）`

标题之后到下一个日期标题之间的内容就是这条小纸条的正文，可以用普通 Markdown（段落、列表、代码块等）。非日期的小标题会当作正文的一部分保留。

## 生成规则

- 所有文件里的条目会合并后按时间倒序排列（新的在前）。
- 页面按内容长度动态分页：每页正文预算约 6000 字符，且最多 20 条，超过就自动分到下一页。
- 输出为 `dist/pieces/index.html`、`dist/pieces/2.html`、……

> 本文件 `README.md` 会被构建脚本忽略。
